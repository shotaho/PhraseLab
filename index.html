書き出し

印刷用の楽譜は「楽譜」タブの「印刷 / PDF」から。伴奏音源はJSONに含まれません。

このアプリについて

データはこの端末のブラウザ内(IndexedDB)にだけ保存されます。ブラウザのデータを消すと失われるので、大事な曲は JSON で書き出しておいてください。

キー操作(PC): Space 再生/停止、Delete 削除、↑↓ 半音、Shift+↑↓ オクターブ、←→ 移動、Ctrl+Z / Ctrl+Y、Ctrl+C / V / D / A
