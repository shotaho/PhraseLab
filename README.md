# PhraseLab

伴奏の音源を聴きながら、旋律(特にサックスなどの管楽器)を作る・直すための Web アプリです。
サーバーは使わず、HTML/JS だけで動きます。スマホ(Android の Chrome)と PC の両方で使えます。

## 使い方

1. 静的ファイルとして配信して開きます(例: GitHub Pages)。
   - ローカルで試す場合: `python3 -m http.server` を実行し、`http://localhost:8000/` を開きます。
2. 初回起動時に、サンプル曲(アルトサックス、90 BPM、4/4、実音 A♭マイナー)が入ります。
3. 「設定 → 伴奏音源」で mp3 / wav / m4a を選びます。音源はこの端末のブラウザ内に保存されます。
4. 「伴奏を頭から再生」を押し、小節1の頭で「ここが小節1」を押します。ずれは微調整(ms)で詰めます。
   クリック(メトロノーム)を鳴らすと合わせやすくなります。

## 画面

| タブ | 内容 |
|---|---|
| ピアノロール | 横軸は小節・拍、縦軸は音高です。下に伴奏の波形と、上部にコードを表示します。 |
| 楽譜 | 五線譜を表示します(実音/記譜、調号あり/なしを切り替え)。印刷から PDF にできます。 |
| 設定 | 曲名、テンポ(タップ可)、拍子、調、小節数、表示範囲、楽器、音色、伴奏、コード進行を設定します。 |
| ファイル | MIDI / MusicXML / JSON の読み込みと書き出しを行います。 |

### ピアノロールの操作

- **ペン**: 空きマスをタップすると音を置きます。選択中にタップすると、選択を解除します。
  長押ししてからドラッグすると、範囲選択になります。空きマスをドラッグすると、画面が動きます。
- **選択**: ドラッグで囲んで、まとめて選択します。
- 音をドラッグすると位置と高さが変わり、右端をドラッグすると長さが変わります。
- 2本指のピンチで拡大・縮小します(横に広げると時間方向、縦に広げると音高方向)。
- 下の編集バーで、半音・オクターブの上下、移動、長さ、表情、コピー、貼り付け、反復、削除ができます。
  貼り付けは再生位置に入ります。
- 小節番号の欄をタップすると、再生位置が移動します。コード欄をタップすると、その小節のコードを入力できます。
- PC のキー操作: Space(再生/停止)、Delete、↑↓(半音)、Shift+↑↓(オクターブ)、←→(移動)、
  Shift+←→(長さ)、Ctrl+Z / Ctrl+Y、Ctrl+C / V / D(反復) / A

### トラック(案)

上部のトラック選択で、案A・案B などを切り替えます。再生されるのは選んでいるトラックだけなので、
切り替えて聴き比べられます。「⋯」から、新規作成・複製・名前変更・削除ができます。
他の案は、ピアノロールに薄い枠で表示されます(「他の案」で表示を切り替えます)。

## データのルール

- 音は常に**実音**の MIDI 番号と tick(4分音符 = 480)で持ちます。移調は表示と書き出しのときだけ行います。
- 楽譜と MusicXML では、1小節を拍子どおりの長さにそろえます。小節や拍をまたぐ音は、タイでつなぎます。
  3連符を含む拍は、3連として書きます。
- 読み込んだ旋律がプロジェクトの小節数を超える場合は、警告を出して小節数を増やします。
  MusicXML の小節が拍子と合わない場合(弱起など)は、警告を出して拍子どおりの長さに整えます。
- 6/8・9/8・12/8 は、付点4分音符を1拍としてテンポを数えます。

## 書き出し

- MIDI: 実音で出力します(テンポ・拍子・調号を含みます)。
- MusicXML: 楽器の移調に合わせた記譜で出力します(`<transpose>` 付き)。調号あり/なしを選べます。
- JSON: プロジェクト全体を出力します。伴奏音源は含まれません。

## 構成

```
index.html
css/style.css
js/theory.js       時間・調・音名の綴り
js/instruments.js  楽器プリセット
js/model.js        プロジェクト構造・サンプル・Undo
js/store.js        IndexedDB
js/synth.js        Web Audio 簡易合成(フォルマント/ビブラート/スクープ/フォール)
js/transport.js    再生(伴奏の audio 要素とメロディ合成の同期、ループ、速度変更)
js/pianoroll.js    ピアノロールと波形
js/notation.js     音符・休符への分解(タイ・3連・連桁・臨時記号)
js/score.js        楽譜描画(VexFlow)
js/midi.js         MIDI 読み書き
js/musicxml.js     MusicXML 読み書き
js/app.js          画面と操作
js/vendor/         VexFlow 4.2.5(MIT)
tests/core.test.js `node tests/core.test.js`
```

## 制限と、将来の対応

- テンポ・拍子の途中変更、複数楽器の同時編集、Android アプリ化(PWA/Capacitor)、
  伴奏からのコード自動推定、伴奏と合成音を重ねた音声の書き出しには、まだ対応していません。
- 圧縮形式の MusicXML(.mxl)は、展開してから読み込んでください。
- 速度変更はブラウザの機能(`preservesPitch`)を使うため、音質はブラウザによって変わります。
